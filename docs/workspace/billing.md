# 查看账单

工作台的「账单」标签页和客户端的「账单」页内容一致：点数余额、套餐信息、消耗记录和兑换入口。

## 页面内容

- **当前可用点数**：套餐周期额度剩余 + 加油包剩余。
- **套餐信息**：当前订阅的档位和周期。
- **套餐与加油包**：可购买档位的展示，实际开通方式见[购买套餐和加油包](/billing/purchase)。
- **兑换码**：输入销售提供的兑换码，立即到账，见[兑换码](/billing/redeem)。
- **消耗记录**：按动作类型和日期展示点数消耗明细。

## 消耗记录里的动作类型

| 动作 | 含义 |
| --- | --- |
| AI 客服回复 | AI 回复顾客消息 |
| 商品学习整理 | 用大模型整理商品资料 |
| 整理回答内容 | 知识入库时的内容处理 |
| 挑选回答依据 | 回答时筛选参考资料 |

各动作的计点规则见[点数怎么计算](/billing/points)。

## 常见问题

**余额和预期对不上？**
按日期展开消耗记录，先看是哪类动作消耗的。商品学习是一次性的批量消耗，容易被忽略。

**套餐点数和加油包点数先扣哪个？**
先扣套餐周期内的额度，用完再扣加油包。

**周期没用完的点数会结转吗？**
不会。套餐点数按 30 天周期发放，周期结束清零；加油包点数按自身有效期计算。
