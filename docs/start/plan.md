# 套餐与开通

熠智 AI 按「套餐 + 点数」计费。这一页讲清套餐的结构；点数怎么扣见[点数怎么计算](/billing/points)。

## 套餐结构

- **订阅套餐**：按月或按年订阅。客服接待点数每 30 天发放一次，周期内没用完不结转。运营助手使用另一份额度，按自然月累计，每月 1 日重置。
- **加油包**：一次性购买的客服接待点数包。套餐点数用完后自动消耗加油包点数。部分加油包有有效期，部分永久有效，购买时会注明。加油包不包含运营助手额度。
- **兑换码**：销售发放的码，可兑换套餐或点数，见[兑换码](/billing/redeem)。

具体档位、价格、额度和开放能力可能调整，以客户端「账单」页当前展示和销售报价为准。

## 套餐权益差异

不同档位除了点数额度，还会限制部分能力，常见的有：

| 权益 | 说明 |
| --- | --- |
| 客服账号接入位 | 每个接入的客服账号占一个接入位，可用数量按套餐开放 |
| AI 方案数量 | 低档位限制方案数量 |
| 情景与触发规则 | 按不同客户情景分流回复，见[情景与触发规则](/solution/triggers)，部分档位开放 |
| 商品智能学习 | 用大模型整理商品资料，见[商品学习](/knowledge/product-learn)，部分档位开放 |

客户端里标注「需开通」的功能，表示当前套餐未包含。想开通请联系销售。

## 怎么开通

目前**不支持在线支付**。开通流程是：

1. 通过客户端菜单里的「联系我们」或官网找到销售。
2. 确认档位和时长，完成付款。
3. 销售开通到账号，或发给你兑换码，在「账单」页自助兑换。

详见[购买套餐和加油包](/billing/purchase)。

## 查看当前套餐

打开客户端左侧菜单「账单」，页面顶部显示当前可用点数和套餐额度，消耗记录会列出每类动作实际扣了多少。网页工作台的「账单」标签页内容相同。
