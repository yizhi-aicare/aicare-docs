# 转接不能用

AI 判断要转人工，却回复顾客“没有客服在线”或转接失败，最常见的原因是店铺没有配置转接对象。有两种处理方式，推荐第一种。

## 方式一（推荐）：给店铺配置转接对象

1. 打开「店铺客服」，在对应店铺的操作按钮里点「店铺设置」。
2. 在「转接客服」区域点「同步转接对象」，把平台上已有的客服和客服组同步进来。同步前先在平台窗口打开一个顾客会话，确保界面上有转接按钮。
3. 按需添加转接用途（如售前、售后），把「未分配客服」里的客服分配到对应用途，再用优先级排序。

![店铺客服页，店铺分组右侧的「店铺设置」按钮](/images/faq/shop-settings-entry.png)

未分配用途的客服不会接到转接。配置细节见[转人工设置](/solution/transfer)。

## 方式二：开启宽松转接

打开左侧菜单的「设置」，进入「工作」，打开「启用宽松转接」。

![设置页「工作」分区里的「启用宽松转接」开关](/images/faq/loose-transfer-setting.png)

开启后，店铺未配置转接对象、或配置的对象都不在线时，系统会随机选择一个在线客服兜底转接（优先客服组），并弹出本地通知提醒该店铺没有配置可用客服。在转接配置里停用的对象不会被选中。

配置的对象在线但转接失败时，宽松转接不会兜底。宽松转接默认关闭，转给谁不可控，只适合临时应急。长期使用请按方式一配置。

::: warning 闲鱼不支持转人工
闲鱼当前无法转人工，需要人工在平台侧接管。
:::
