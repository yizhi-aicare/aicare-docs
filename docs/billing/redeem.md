# 兑换码

兑换码是目前最常用的开通方式：销售确认订单后发码给你，自助兑换即时到账。

## 兑换步骤

1. 打开客户端左侧菜单「账单」（或网页工作台的「账单」标签页）。
2. 找到「兑换码」输入框。
3. 输入销售提供的兑换码，点击兑换。
4. 兑换成功后页面立即刷新，套餐或点数直接到账。

## 兑换须知

- 兑换码**不区分大小写**，大小写输错了也能兑。
- 每个码只能兑换一次。
- 短时间内连续尝试多次会触发频率限制，稍等再试。
- 码可能对应套餐、也可能对应点数加油包，以购买时和销售确认的内容为准。

## 常见问题

**提示兑换码无效？**
逐字核对（注意数字 0 和字母 O、数字 1 和字母 l），确认没有多复制空格。核对无误仍失败的，找销售确认码的状态。

**提示已被使用？**
兑换码只能用一次。如果你自己没兑过，联系销售核实。

**兑错账号了怎么办？**
兑换直接作用于当前登录账号，无法自助转移。尽快联系销售处理。

**兑换的套餐什么时候生效？**
兑换成功即生效，「账单」页顶部的套餐信息和可用点数会立即更新。
