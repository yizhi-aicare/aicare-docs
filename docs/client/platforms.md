# 支持的平台

熠智 AI 目前支持以下电商平台：

| 平台 | AI 接待 | 商品学习 | 转人工 | 说明 |
| --- | --- | --- | --- | --- |
| 千牛 / 淘宝 | 支持，仅 Windows | 支持，仅 Windows | 支持 | 依赖本机千牛 |
| 拼多多 | 支持 | 支持 | 支持 | |
| 京东 | 支持 | 支持 | 支持 | |
| 抖音 | 支持 | 支持 | 支持 | |
| 快手 | 支持 | 支持 | 支持 | |
| 闲鱼 | 支持 | 支持 | **不支持** | 见下文 |

## 各平台注意事项

### 千牛 / 淘宝

- AI 接待和商品学习都必须在 **Windows** 电脑上使用。两项能力都依赖 Windows 桌面组件，macOS 无法使用。
- 添加账号时客户端会自动检测本机已登录的千牛窗口，直接选择即可。
- 接待期间千牛需保持登录。

### 闲鱼

- 闲鱼当前**无法转人工**。AI 处理不了的问题需要你自己跟进：请关注客户端通知，并定期查看[聊天记录](/workspace/records)里的待跟进筛选。

### 通用

- 所有平台的接待都在你的电脑上运行，电脑关机或客户端退出后接待停止。
- 平台页面改版可能导致消息读取异常，遇到时先升级客户端到最新版本。
