# 登录客户端

客户端用注册时的手机号登录，支持两种方式，在登录页顶部切换。

## 两种登录方式

- **密码登录**：手机号 + 登录密码。
- **验证码登录**：手机号 + 短信验证码。忘记密码时用这个方式先登进去。

## 保持登录

登录成功后客户端会记住登录状态，下次打开不需要重新输入。如果长时间未使用或在别处修改过密码，可能需要重新登录。

## 常见问题

**收不到短信验证码？**
确认手机号填写正确，检查短信是否被拦截进了垃圾箱。短时间内多次获取会触发频率限制，稍等几分钟再试。

**提示账号或密码错误？**
切换到「验证码登录」确认账号本身可用，登录后再考虑是否需要重置密码。

**登录后是空的？**
新账号还没有接入店铺，属于正常状态。从[接入店铺和客服账号](/client/shops)开始配置。
