# 购买套餐和加油包

目前**不支持在线支付**。购买通过销售完成，之后由销售直接开通或发兑换码自助兑换。

## 购买流程

1. **选档位**：在客户端「账单」页查看各套餐和加油包的说明，或直接把需要接入的客服账号数量、日咨询量告诉销售，让销售推荐。
2. **联系销售**：通过客户端菜单里的「联系我们」，或官网上的联系方式。
3. **确认并付款**：与销售确认档位、时长和价格后付款。
4. **到账**：销售直接开通到你的账号，或发兑换码由你在「账单」页自助兑换，见[兑换码](/billing/redeem)。

## 买套餐还是买加油包

| 情况 | 建议 |
| --- | --- |
| 长期日常使用 | 订阅套餐，周期点数单价更低 |
| 套餐点数在周期结束前用完 | 补一个加油包，下周期再评估是否升档 |
| 大促期间临时放量 | 加油包，避免为短期峰值长期升档 |
| 试用观望 | 从小档位或小加油包开始 |

普通点数加油包只补充客服接待点数，不包含运营助手额度。运营助手额度按自然月单独计算，具体以「账单」页为准。

套餐与点数的关系见[套餐与开通](/start/plan)和[点数怎么计算](/billing/points)。

## 续费与升级

- **续费**：套餐到期前联系销售续费，或兑换新的套餐码。
- **升级**：需要更多客服账号接入位、更多方案，或需要情景分流、表格、商品智能整理等按套餐开放的能力时，联系销售换档。

## 常见问题

**能开发票吗？**
和销售确认，按公司流程开具。

**价格在哪看？**
「账单」页展示各档位说明，最终价格以销售报价为准。
