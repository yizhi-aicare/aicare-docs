# 录入问答和文档

知识库的「知识项」标签页支持四种录入方式。按内容形态选合适的方式，AI 检索效果会更好。

## 四种录入方式

### 问答

一问一答的形式，最推荐的方式。问题写顾客的问法，答案写你希望 AI 参考的说法。

```
问：多久发货？
答：默认 48 小时内发货，预售商品以商品页标注为准。
```

### 文本

一段独立的说明文字，适合不成问答形式的资料，比如一段售后流程说明。

### Markdown 文档

把整篇 Markdown 文档贴进来，系统会**按标题章节自动拆分**成多个知识片段。适合已有成型文档的场景。也支持导入 Word / PDF 等文档资料。

### Excel 批量导入

批量上传问答：Excel 每行一对问题和答案。适合把客服团队积累的话术表一次性灌进来。

## 写好知识内容的要点

- **一条只讲一件事**。「发货时效」和「退换政策」分成两条，别堆在一起——检索是按条命中的。
- **问题用顾客的原话**。顾客问「什么时候能到」而不是「物流时效咨询」。翻聊天记录找真实问法。
- **答案写完整**。AI 会参考答案组织语言，答案本身含糊，AI 也答不清楚。
- **有时效的内容标注清楚**。活动话术写上活动时间，过期后及时删除。

## 待审核条目

部分自动产生的知识项（比如 AI 从接待中整理的问答）会带**待审核**状态。审核确认后才会正式参与回答。收到「AI 推送待办信息」通知时，来这里处理。

## 修改和删除

- 问答、文本、文档类型的知识项可以直接编辑。
- 商品学习产生的商品资料不在知识项里改，去「商品」标签页维护，见[商品学习](/knowledge/product-learn)。
- 支持多选批量删除。

## 常见问题

**内容录了但 AI 没答上来？**
先检查库是否绑定到了当前方案，再用[对话测试](/solution/test)复现，看引用了什么资料。详细排查见[回答不准怎么办](/faq/accuracy)。

**知识条数有上限吗？**
知识库和商品库条数不设限。
