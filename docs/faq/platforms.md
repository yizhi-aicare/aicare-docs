# 平台支持问题

关于平台支持的高频问题。完整的支持矩阵见[支持的平台](/client/platforms)。

## 支持哪些平台？

千牛/淘宝（仅 Windows）、拼多多、京东、抖音、快手、闲鱼。

## 为什么千牛只能在 Windows 上用？

千牛的 AI 接待和商品学习都依赖 Windows 桌面组件，macOS 上没有对应能力。计划接入千牛/淘宝的商家请准备 Windows 电脑。

## 闲鱼为什么不能转人工？

闲鱼当前不支持转人工。闲鱼店铺的替代做法：

1. 关注客户端通知。
2. 每天处理[聊天记录](/workspace/records)里的待跟进会话。

## 电脑关机了 AI 还会接待吗？

**不会。** 接待在你的电脑上运行，电脑关机、客户端退出、平台窗口关闭，接待都会停止。这是产品的工作方式——你的店铺账号只在自己电脑上登录。

晚上无人值守的时段，用[夜间服务模式](/solution/general#服务策略)自动应答并留言跟进。

## 一台电脑能带几个店铺？

电脑本身没有固定的店铺数量限制。套餐限制的是客服账号接入位：每接入一个平台客服账号会占用一个接入位。可用数量以「账单」页当前套餐说明为准，见[接入店铺和客服账号](/client/shops)。

## 可以多台电脑同时接待吗？

可以，同一账号可在多台电脑登录客户端，不同店铺分布在不同电脑上接待。同一个平台客服账号同一时间只在一台电脑上接待。各台电脑的在线状态可以在工作台的「设备」标签页查看。

## 平台改版导致接待异常怎么办？

先把客户端升级到最新版本——平台页面改版的适配修复通过客户端更新发布。升级后仍异常的，[生成错误报告](/client/report)反馈。
