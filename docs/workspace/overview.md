# 工作台总览

网页工作台是浏览器里的管理后台。人不在接待电脑旁时，可以随时登录查看数据、调整配置。

::: tip 工作台不做接待
接待本身在桌面客户端运行。工作台负责「看」和「配」，改动会同步到客户端生效。
:::

## 登录

打开 [www.yizhi.chat](https://www.yizhi.chat/)，用注册的手机号登录，即进入工作台。

## 功能分区

工作台顶部按三组组织标签页：

### 常用功能

| 标签 | 作用 |
| --- | --- |
| 运营助手 | 对话式配置副驾：帮你配方案、查异常回复、整理知识库 |
| 仪表盘 | 查看核心统计、接待数据和待处理事项 |
| 数据分析 | 工具调用次数、转接对象占比与转接成功率 |
| 聊天记录 | 按平台和顾客查看客户对话记录，见[聊天记录与数据](/workspace/records) |
| 知识库 | 集中管理可复用的店铺资料，见[管理知识库](/workspace/knowledge) |

### AI 接待

| 标签 | 作用 |
| --- | --- |
| AI方案 | 设置接待规则、标准回复和人工接手，见[管理 AI 方案](/workspace/solutions) |
| 商品信息 | 维护商品参数、卖点、尺码和售后说明 |
| 表格 | 管理供智能体使用的查询表与登记表，见[查询表与登记表](/solution/tables) |
| 催付提醒 | 设置催付、回访等自动提醒 |
| 对话测试 | 用真实顾客问法检查 AI 能否答上来 |

### 店铺维护

| 标签 | 作用 |
| --- | --- |
| 通知 | 处理公告、业务提醒和异常消息；含微信通知绑定入口 |
| 异常记录 | 查看接待异常和需要跟进的问题 |
| 设备 | 查看各台电脑的在线状态、版本和坐席 |
| 账单 | 查看剩余点数、兑换权益和开通记录，见[查看账单](/workspace/billing) |

## 运营助手

「运营助手」和客户端里的「AI 助手」是同一个能力：用聊天的方式问它店铺配置、让它检查知识库、请它提修改建议。它的修改建议**需要你确认后才生效**，已应用的修改可以撤销。

## 用语差异说明

工作台和客户端个别用词不同，指的是同一个东西：

- 工作台的「AI方案」里可能把方案下的回复角色叫「接待角色」，客户端里叫「智能体」或「情景」。
- 工作台「对话测试」对应客户端方案编辑器里的「对话测试」。
