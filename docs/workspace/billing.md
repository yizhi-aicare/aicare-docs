# 查看账单

工作台的「账单」标签页和客户端的「账单」页内容一致：点数余额、套餐信息、消耗记录和兑换入口。

## 页面内容

- **当前可用点数**：客服接待的套餐周期额度剩余 + 加油包剩余，不含运营助手额度。
- **套餐信息**：当前订阅的档位和周期。
- **套餐与加油包**：可购买档位的展示，实际开通方式见[购买套餐和加油包](/billing/purchase)。
- **兑换码**：输入销售提供的兑换码，立即到账，见[兑换码](/billing/redeem)。
- **消耗记录**：按动作类型和日期展示实际点数消耗明细。AI 回复的单次消耗不是固定值，以这里的记录为准。

## 消耗记录里的动作类型

| 动作 | 含义 |
| --- | --- |
| AI 客服回复 | AI 回复顾客消息 |
| 商品学习整理 | 每生成一份整理后的商品资料 |
| 整理回答内容 | 知识入库时的内容处理 |
| 挑选回答依据 | 回答时筛选参考资料 |

各动作的计点规则见[点数怎么计算](/billing/points)。

## 运营助手额度

运营助手使用单独额度，按自然月累计并在每月 1 日重置。普通点数加油包不包含运营助手额度；是否开放和当月额度以当前套餐说明为准。

## 常见问题

**余额和预期对不上？**
按日期展开消耗记录，先看是哪类动作消耗的。商品学习按生成的商品资料计点，一次整理多个商品时，总消耗会随实际生成的资料数量增加。

**套餐点数和加油包点数先扣哪个？**
先扣套餐周期内的额度，用完再扣加油包。

**周期没用完的点数会结转吗？**
不会。套餐点数按 30 天周期发放，周期结束清零；加油包点数按自身有效期计算。
