# 下载安装客户端

日常接待在桌面客户端完成。客户端目前提供 **Windows 安装包**。

## 下载

1. 打开官网 [www.yizhi.chat](https://www.yizhi.chat/)。
2. 点击导航里的「下载软件」，进入下载页。
3. 下载最新版本的 Windows 安装包。

网页工作台的右上角也有「下载软件」入口，指向同一个下载页。

## 安装

1. 双击下载好的安装包，按提示完成安装。
2. 首次打开会进入登录页，用注册时的手机号登录，见[登录客户端](/client/login)。

::: tip 系统要求
- 接入**千牛/淘宝**必须使用 Windows。千牛的接待能力依赖 Windows 桌面组件，macOS 上无法使用。
- 其余平台（拼多多、京东、抖音、快手、闲鱼）的接待同样以 Windows 客户端为准。
:::

## 更新

客户端会检查新版本并提示更新。收到更新提示时建议尽快升级，新版本包含平台适配修复——电商平台页面改版后，旧版本可能无法正常读取消息。

## 常见问题

**安装时被安全软件拦截怎么办？**
选择「允许运行」。客户端需要操作平台窗口来收发消息，部分安全软件会对这类行为提示确认。

**可以装在多台电脑上吗？**
可以。同一账号可在多台电脑登录客户端，但同一个平台客服账号同一时间只在一台电脑上接待。
