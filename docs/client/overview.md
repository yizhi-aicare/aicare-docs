# 客户端总览

登录桌面客户端后，左侧是主菜单。这一页帮你建立一张地图，知道每个入口是干什么的。

## 左侧菜单

| 菜单 | 作用 | 详细文档 |
| --- | --- | --- |
| 店铺客服 | 接入店铺、管理客服账号、开关每个账号的 AI 接待 | [接入店铺和客服账号](/client/shops) |
| 店铺方案 | 创建和编辑 AI 方案，决定 AI 怎么回复 | [方案编辑器](/solution/editor) |
| AI 助手 | 运营助手：用对话方式了解店铺配置、获取调整建议 | 见下文 |
| 工作台 | 汇总当前接待中的会话和待办 | — |
| 扩展市场 | 管理知识库（我的库 / 公共库），了解高级能力 | [知识库是什么](/knowledge/basics) |
| 表格 | 创建查询表和登记表，供 AI 查数据、记需求 | [查询表与登记表](/solution/tables) |
| 聊天记录 | 按顾客查看会话记录，筛选待跟进会话 | [聊天记录与数据](/workspace/records) |
| 数据统计 | 接待量等统计数据 | — |
| 账单 | 点数余额、套餐、消耗记录、兑换码 | [点数怎么计算](/billing/points) |

菜单下方还有「设置」入口和「联系我们」「新手教程」等辅助入口。

## 设置页

设置页按分区组织：

- **缓存 / 启动**：清理缓存、开机自启动等。
- **通知**：客户端提醒、微信绑定和通知记录，见[通知设置](/client/notify)。
- **错误上报**：控制报错时保存和上报的内容范围，见[错误报告](/client/report)。
- **工作**：接待运行方式，包括「同时处理多个客户」（默认关闭，每次只处理 1 个客户）和「启用宽松转接」（默认开启，见[转人工设置](/solution/transfer#宽松转接)）。
- **新客服默认打开方式**：添加新客服时窗口如何呈现。
- **高级**：调试工具，日常使用不需要。

## AI 助手（运营助手）

「AI 助手」是一个对话式的运营助手。你可以直接问它店铺的配置情况、让它检查知识库、或请它提出调整建议。

它给出的**修改建议需要你确认后才会生效**，已应用的修改支持撤销。放心提问，不会因为聊了几句就改动配置。

## 接待时的窗口

在「店铺客服」里打开某个客服账号后，客户端会打开对应平台的客服窗口。AI 在这个窗口里读消息、发回复。接待期间保持客户端和平台窗口运行即可，可以最小化。
