# 支持的平台

熠智 AI 目前支持以下电商平台的客服接待：

| 平台 | AI 接待 | 转人工 | 说明 |
| --- | --- | --- | --- |
| 千牛 / 淘宝 | 支持 | 支持 | 仅 Windows，依赖本机千牛 |
| 拼多多 | 支持 | 支持 | |
| 京东 | 支持 | 支持 | |
| 抖音 | 支持 | 支持 | |
| 快手 | 支持 | 支持 | |
| 闲鱼 | 支持 | **不支持** | 平台侧无转接协议，见下文 |

**1688 目前不支持。** 如果你主要在 1688 经营，暂时无法使用熠智 AI 接待。

## 各平台注意事项

### 千牛 / 淘宝

- 必须在 **Windows** 电脑上使用。千牛接待依赖 Windows 桌面组件，macOS 无法使用。
- 添加账号时客户端会自动检测本机已登录的千牛窗口，直接选择即可。
- 接待期间千牛需保持登录。

### 闲鱼

- 闲鱼平台没有客服转接协议，因此**无法转人工**。AI 处理不了的问题只能提醒你自己跟进：建议开启[通知设置](/client/notify)里的相关事件，并定期查看[聊天记录](/workspace/records)里的待跟进筛选。

### 通用

- 所有平台的接待都在你的电脑上运行，电脑关机或客户端退出后接待停止。
- 平台页面改版可能导致消息读取异常，遇到时先升级客户端到最新版本。
