# 遇到故障怎么反馈

软件出问题时怎么自查、怎么反馈能最快得到解决。

## 先做三件事

1. **升级客户端**。平台页面改版导致的问题（消息读不到、发不出）通常已经在新版本修复。
2. **重启客户端**。关掉重开，让平台窗口重新加载。
3. **确认平台账号状态**。账号是否在别处被登出、平台是否要求重新验证。

大部分「AI 突然不回了」的情况到这里就解决了。

## 还没解决：生成错误报告

1. 点击客户端右上角的点数余额，在弹出的账户卡片底部点「遇到问题？上报错误」。
2. 在弹窗里填写错误描述（必填）：**什么平台、什么时间、发生了什么、预期是什么**。
3. 点「上报」，客户端把近三天的日志打包上传（最大 20MB）。

![点数余额弹出的账户卡片，底部的「遇到问题？上报错误」入口](/images/faq/report-error-entry.png)

上报成功后客户端会显示报告编号。影响持续时，在微信服务群（入口在客户端「联系客服」里）报上这个编号，支持人员即可找到对应日志。详见[错误报告](/client/report)。

## 接待类问题去哪看

- **AI 回复内容不对**：不算故障，按[回答不准怎么办](/faq/accuracy)排查配置。
- **转人工失败**：先看[转接不能用](/faq/transfer)，再看[转人工设置](/solution/transfer)的排查建议，以及工作台「数据分析」里的转接成功率。
- **接待异常记录**：工作台「异常记录」标签页汇总了需要跟进的接待问题。

## 反馈时的隐私说明

- 自动上报只包含报告 ID 和必要摘要。
- 页面截图和 HTML 快照默认只保存在你的电脑上，仅在你主动上报错误时随日志包上传。
- 可以在「设置 → 错误上报」里关闭详细材料的本地保存，见[错误报告](/client/report#错误上报设置)。

## 紧急情况

接待完全中断且影响生意时，直接在微信服务群里说明「接待中断」，并附上错误报告 ZIP。这类问题会优先处理。
