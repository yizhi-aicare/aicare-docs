# 错误报告

软件出问题时，一份完整的错误报告能让支持人员更快定位原因。这一页讲怎么生成报告、以及错误上报设置的含义。

## 生成错误报告

1. 点击客户端右上角的点数余额，在弹出的账户卡片底部点「遇到问题？上报错误」。
2. 填写错误描述（必填）：发生时间、平台、店铺和客服账号、正在做什么、能否稳定复现。
3. 点「上报」，客户端把近三天的日志打包上传（最大 20MB），成功后显示报告编号。联系客服时报上这个编号，支持人员即可找到对应日志。

![点数余额弹出的账户卡片，底部的「遇到问题？上报错误」入口](/images/faq/report-error-entry.png)

## 错误上报设置

入口：「设置」→「错误上报」。

**本地保存详细错误材料**开关控制报错时保存的内容范围：

- 开启后，平台脚本报错时会把当前页面截图和 HTML 快照保存到本地错误报告目录。
- 自动上报只发送报告 ID 和必要摘要，**不包含**截图与快照。
- 截图与快照仅在你主动「上报错误」时随日志包一起上传，用于排查问题。

如果你对页面内容敏感，可以关闭这个开关，代价是排查平台页面相关的问题会慢一些。

## 什么时候需要报错

- AI 停止回复、消息读取异常。
- 平台窗口反复掉线或行为异常。
- 客户端崩溃、卡死。

报错前建议先做两件事：升级客户端到最新版本、重启客户端。很多平台页面改版引起的问题在新版本里已经修复。
