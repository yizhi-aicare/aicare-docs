# 关键词回复

关键词回复的优先级**高于 AI**：顾客消息命中关键词后，直接用你配置的话术回复，AI 不参与。适合活动话术、固定答案这类不想让 AI 自由发挥的场景。

入口：方案编辑器 → 「关键词设置」。

## 三种匹配方式

| 匹配方式 | 命中条件 | 例子 |
| --- | --- | --- |
| 包含 | 消息里含有关键词即命中 | 关键词「发货」命中「什么时候发货呀」 |
| 全匹配 | 消息与关键词完全一致才命中 | 关键词「1」只命中顾客单发「1」 |
| 正则表达式 | 消息匹配正则规则时命中 | `^(在吗|在不在)[?？]?$` |

日常用「包含」就够了。「全匹配」适合让顾客回数字选选项的场景。正则给熟悉的人用，不熟悉就跳过。

## 添加关键词

1. 点「添加关键词」。
2. 填关键词、选匹配方式、写回复话术。
3. 保存后立即生效。

## 批量导入

支持 Excel 导入，一次最多 2000 行。页面上可下载模板，按模板格式填好后上传。大促前批量导入活动话术很实用。

## 使用建议

- **别配太宽的词**。「包含」匹配下，关键词「好」会命中「好的」「还没好吗」，把不该拦的消息拦下来。宁可具体一点。
- **固定答案才用关键词**。需要看上下文回答的问题（比如「这个和那个哪个好」）交给 AI 和知识库。
- **活动结束记得停用**。过期的活动话术继续命中会误导顾客。

## 和知识库的区别

| | 关键词回复 | 知识库 |
| --- | --- | --- |
| 命中方式 | 字面匹配 | 语义检索，问法不同也能命中 |
| 回复内容 | 原样发送你写的话术 | AI 参考资料组织语言 |
| 适合 | 固定话术、活动通知 | 政策、商品知识等需要理解的问题 |
